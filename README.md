# SNHU CS320: Software Testing, Automation, and Quality Assurance

Final Project containing three services and unit tests

## Reflection

#### How can I ensure that my code, program, or software is functional and secure?

* Write clean, well-documented code with clear variable names and comments
* Follow secure coding practices like input validation, error handling, and proper memory management
* Use a combination of manual and automated testing to cover various scenarious
* Leverage tools that analyze code for potential bugs, security vulnerabilities, and coding standard violations
* Conduct code reviews to examine code for functionality, security, and maintainability

#### How do I interpret user needs and incorporate them into a program?

* User Research: Identify user needs and desired functionalities
* User Stories: Translate user needs into user stories
* Prioritization: Prioritize user stories based on importance and impact
* Iterative Development: Develop software iteratively and gather feedback early to incorporate it into future iterations

#### How do I approach designing software?

* Define the problem and scope
* Select a Software Development Life Cycle methodology
* Create a high-level overview of the software architecture
* Break down the system into smaller modules or classes
* Define the interfaces, functionalities, and interactions between modules
* Design the data structures to store and manage the data
* Start coding based on design documents and follow coding best practices to maintain clean, well-documented code
* Test software with both manual and automated testing strategies
